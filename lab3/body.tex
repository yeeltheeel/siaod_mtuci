Целью данной лабораторной работы является:
\begin{itemize}
	\item изучить методы анализа структуры ориентированных и неориентированных графов;

	\item научиться определять условия применимости каждого метода.
\end{enumerate}

При представлении списком смежности каждая вершина хранится один раз, и для нее хранится список ее соседей.
Обход графа и помечение каждой посещенной вершины равно O(V).
Просмотр всех элементов списков смежности для каждой вершины -- O(E).
Таким образом, общая сложность равна O(V) + O(E) = O(V + E).

\ssr{Контрольные вопросы}
\begin{enumerate}
	\item \textit{Что такое список смежности и какова стоимость обхода графа при таком представлении?}\newline
	Список смежности -- структура вида {вершина: [соседи]}, где для каждой вершины хранится список смежных с ней вершин (и, при необходимости, весов ребер).
	Обход (DFS или BFS) стоит O(V + E): каждая вершина обрабатывается один раз, а каждый элемент списков смежности просматривается один раз (для неориентированного графа -- дважды).
	\item \textit{Чем компонента сильной связности отличается от обычной компоненты связности?}\newline
	Компонента связности (в неориентированном графе) -- максимальное множество вершин, между любыми двумя из которых существует путь (достаточно пути в одну сторону). 
	Компонента сильной связности (в ориентированном графе) -- максимальное множество вершин, в котором для любых u, v существует путь (u, v) и путь (v, u).
	\item \textit{Из каких основных этапов состоит алгоритм Косарайю?}\newline
	Алгоритм Косарайю состоит из трех этапов: 
	а) DFS по исходному графу с сохранением вершин в порядке завершения обработки (post-order); 
	б) построение транспонированного графа; 
	в) DFS по графу из предыдущего пункта, запускаемый в обратном порядке относительно выхода из первого DFS.
	\item \textit{Какую роль играют tin и low при DFS?}\newline
	tin[v] -- время первого посещения вершины v при DFS (счетчик увеличивается на каждом входе). 
	low[v] -- минимальное значение tin, достижимое из v и ее DFS-поддерева с использованием ребер дерева и не более одного обратного ребра. 
	Эти величины позволяют находить мосты и точки сочленения за один обход.
	\item \textit{Как определяется мост через значения tin и low?}\newline
	Мост -- ребро дерева DFS (v, to), для которого low[to] > tin[v]. 
	\item \textit{Что называется точкой сочленения и чем отличается обработка корня DFS?}\newline
	Точка сочленения -- вершина, удаление которой вместе с инцидентными ребрами увеличивает число компонент связности. 
	\item \textit{Что такое DAG?}\newline
	DAG (Directed Acyclic Graph) -- ориентированный граф без ориентированных циклов.
	\item \textit{Что означает топологический порядок и когда он существует?}\newline
	Топологический порядок -- линейное упорядочение вершин, при котором для каждого ребра (u, v) вершина u стоит раньше v. 
	Он существует тогда и только тогда, когда граф является DAG (не содержит циклов).
	\item \textit{Как с помощью DFS обнаружить цикл в ориентированном графе?}\newline
	При DFS вершины раскрашиваются в три состояния: 0 -- не посещена, 1 -- в текущем стеке DFS, 2 -- обработана. 
	Если из текущей вершины обнаружено ребро в вершину со состоянием 1, это обратное ребро, то цикл есть.
	\item \textit{Что называется релаксацией ребра?}\newline
	Релаксация ребра (u, v) с весом w -- операция вида:
\begin{lstlisting}[language=python]
if dist[v] > dist[u] + w: 
	dist[v] = dist[u] + w
	parent[v] = u
\end{lstlisting} 
	Она пытается улучшить известное расстояние до v, используя путь через u.
	\item \textit{При каких условиях корректен алгоритм Дейкстры?}\newline
	При неотрицательных весах ребер.
	\item \textit{Зачем в Дейкстре используется приоритетная очередь?}\newline
	Приоритетная очередь в алгоритме Дейкстры нужна для эффективного выбора вершины с минимальным текущим расстоянием.
	\item \textit{Как восстановить маршрут после поиска кратчайших расстояний?}\newline
	При каждой успешной релаксации сохраняется parent[v] = u. 
	После завершения алгоритма начинается от конечной вершины по parent до стартовой, во время которого собираются вершины.
	Полученный список затем разворачивается.
	\item \textit{Почему отрицательные рёбра создают проблему для алгоритма Дейкстры?}\newline
	Отрицательные ребра ломают жадность: вершина, расстояние до которой уже зафиксировано как минимальное, позже может получить более короткий путь через отрицательное ребро.
	\item \textit{Как работает алгоритм Беллмана–Форда?}\newline
	Беллман–Форд выполняет V-1 полных проходов по всем ребрам, на каждом проходе ослабляя все ребра. 
	Если на очередном проходе не было ни одной релаксации, алгоритм завершается досрочно.
	\item \textit{Почему для кратчайшего пути без отрицательных циклов достаточно V-1 итераций релаксации?}\newline
	Достаточно V-1 итераций, потому что любой простой путь (без повторных вершин) из V вершин содержит не более V-1 ребер. 
	\item \textit{Как Беллман–Форд обнаруживает отрицательный цикл?}\newline
	После V-1 итераций выполняется еще один проход по всем ребрам. 
	Если хотя бы одно ребро можно ослабить (dist[u] + w < dist[v]), то существует цикл отрицательного веса, достижимый из старта, и конечного кратчайшего расстояния для некоторых вершин не существует.
	\item \textit{Какую задачу решает алгоритм Флойда–Уоршелла?}\newline
	Алгоритм Флойд–Уоршелла решает задачу поиска кратчайших расстояний между всеми парами вершин. 
	На шаге k проверяется, можно ли улучшить путь (i, j), разрешив использовать вершину k как промежуточную.
	\item \textit{Какова временная сложность Дейкстры с двоичной кучей, Беллмана–Форда и Флойда–Уоршелла?}\newline
	Сложность Дейкстры с двоичной кучей -- $O((V+E)\log V)$; 
	Беллмана–Форда -- $O(VE)$; 
	Флойда–Уоршелла -- $O(V^3)$ (память $O(V^2)$).
	\item \textit{В каких случаях следует выбирать каждый из трёх алгоритмов кратчайших путей?}\newline
	Для одного источника без отрицательных весов -- алгоритм Дейкстры; 
	для одного источника с возможными отрицательными ребрами -- Беллмана–Форда; 
	для поиска расстояний между всеми парами в графе умеренного размера -- Флойда–Уоршелла.
	Для больших разреженных графов выгоднее Дейкстра из каждой вершины.
\end{enumerate}
